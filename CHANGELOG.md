# ESH Audit updates

## [1.1.0] - 2026-09-10

### Added
- Restorable drafts when creating observations. Text and selections save after a short pause; attach photos again after restoring a draft.
- A What's new page for product updates.
- Subtle click feedback throughout the panel, including navigation menus, respecting reduced motion preferences.

### Changed
- Mobile navigation, stacked table rows, larger touch targets and slide-over forms.
- Compact mobile login and improved presentation layouts.
- Presentation slides load one observation at a time.
- Dashboard statistics refresh once a minute.

### Fixed
- Dashboard date ranges include the whole final day.
- Profile editing and registration include the required username.
- Presentation arrow keys no longer change slides while editing filters.
- Missing logos fall back to the application name.
- Removed an unauthenticated debug endpoint that exposed observation data.
